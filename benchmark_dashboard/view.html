Valkey Data Tiering — Benchmark Config Audit

Every config in benchmark/scenarios/*/configs/ was run end-to-end against this commit on a single aarch64 host with NVMe at /mnt/nvme. Throughput here is not performance data — the audit caps OPS at 200k, DURATION at 10s and KEY_COUNT at 100k so each config is exercised (parse → server start → populate → workload → report) in bounded time. A verdict of PASS means the config runs and reports throughput, not that it is fast.
